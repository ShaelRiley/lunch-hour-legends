==================================================
TITLE-SCREEN BEHAVIOR
==================================================

NEW GAME

- Starts the currently loaded module from its declared opening state.
- When saves already exist, obtain clear confirmation before replacing progress.
- Never delete unrelated module saves.
- Use the loaded module’s compatible starting configuration.
- Fail safely when the module becomes invalid after loading.

CONTINUE

- Continues the most recent compatible save belonging to the currently loaded module.
- Is visibly unavailable when no compatible save exists.
- Never loads a save from another module.
- Reports version incompatibility clearly.
- Provides access to the full save-selection interface when multiple saves exist.

LOAD MODULE

- Opens a local file selector for a prepared lhl.zip file.
- Reads and validates the package without activating it first.
- Displays a preview and validation report.
- Requires explicit activation after successful validation.
- Never replaces the current module when validation fails.
- Preserves the previous active module and its saves.
- Stores the imported package locally after approval.
- Rejects malformed archives, path traversal, unsupported versions, executable payloads, oversized packages, missing files, broken references, and invalid assets.

CREATE MODULE

- Opens the Create Module screen.
- Does not call an LLM API.
- Does not require an account or API key.
- Does not transmit the user’s description.
- Produces a complete prompt locally.
- Allows one-click copy.
- Allows TXT and Markdown download.
- Returns the user to Load Module after an external LLM creates the ZIP.

- save manually;
- update a rotating safe-node autosave;
- receive declared recovery;
- continue;
- return to town.

- ski lift;
- gondola;
- cable car;
- teleporter;
- magical gate;
- elevator;
- shuttle;
- ferry;
- service tunnel;
- river route;
- maintenance exit;
- secret path;
