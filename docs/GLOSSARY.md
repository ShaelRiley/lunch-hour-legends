# Glossary

- **Cartridge / module:** portable `.lhl.zip` containing compiled game data, inspectable sources, assets, reports, and manifest.
- **Activation:** explicit replacement of the launcher’s current module after validation.
- **Failure-safe swap:** a failed candidate never alters the active module.
- **Safe node:** a progression boundary that permits manual save, autosave, recovery, town return, and re-entry.
- **UCS-PB:** Universal Class Specification Point-Buy, the bounded class-generation grammar.
- **Reference module:** the hand-authored Battle of the Bands calibration cartridge.
